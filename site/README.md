# موقع المستشار النظامي

موقع عام يكتب فيه الزائر سؤاله النظامي، فيجيبه Claude تلقائياً من نصوص `مكتبة-التشريعات` مع ذكر المادة واقتباس منها. لا يحتاج الزائر حساباً.

## كيف يعمل
1. المتصفح يحمّل المكتبة (`public/data.json`) ويبحث فيها عن الأقسام المتعلقة بالسؤال.
2. الخادم (`src/worker.js`) يحوّل السؤال إلى مصطلحات نظامية بنموذج سريع، ثم يقرأ الأقسام المختارة من ملفاته (`public/s/`) ويرسلها مع تعليمات الوكيل (`public/rules.txt`) إلى Claude.
3. تظهر الإجابة متدفقة، وتحتها النصوص التي رُجع إليها.

مفتاح Claude محفوظ في الخادم سراً، ولا يصل إلى المتصفح. والخادم لا يرسل إلى Claude إلا نصوصاً من المكتبة، ويحدّ كل زائر بعشرة طلبات في الدقيقة (السؤال الواحد طلبان).

## التشغيل لأول مرة (من المتصفح، بلا أوامر)
1. **مفتاح Claude:** في console.anthropic.com أنشئ حساباً، واشحن رصيداً، وضع **حداً شهرياً للإنفاق** من إعدادات الفوترة، ثم أنشئ مفتاح API.
2. **الاستضافة:** في dash.cloudflare.com أنشئ حساباً مجانياً، ثم: Workers & Pages ← Create ← Import a repository ← اختر المستودع `ahmad`.
   - Root directory: `site`
   - Deploy command: `npx wrangler deploy`
3. **إضافة المفتاح:** بعد أول نشر، من إعدادات الـ Worker ← Variables and Secrets ← أضف `ANTHROPIC_API_KEY` من نوع Secret، والصق المفتاح.
4. يظهر رابط الموقع بصيغة `mustashar.<اسمك>.workers.dev`. ويمكن ربطه لاحقاً بنطاق خاص.

بعدها، كل دمج في `main` يعيد نشر الموقع تلقائياً.

## تحديث المكتبة
عند إضافة نص أو تعديل في `مكتبة-التشريعات` أو في `تعليمات-الوكيل.md`، يُعاد بناء ملفات الموقع:

```
cd site
python3 build_data.py ../مكتبة-التشريعات public
```

## الإعدادات (`wrangler.toml`)
- `ANSWER_MODEL`: نموذج كتابة الإجابة.
- `QUICK_MODEL`: نموذج تحويل السؤال إلى مصطلحات بحث.
- `ratelimits`: حد الطلبات لكل زائر.
