# مكتبة التشريعات

مخزن نصي لمكتبة التشريعات لدى صاحب الممارسة (مجلد "تشريعات مصنفة حسب المجالات")، ليعتمد عليه وكيل التشريعات.

## القواعد

- كل ملف هو نظام أو لائحة أو قرار واحد، وكل مادة فيه عنوان مستقل (`### المادة N`)، ومعها رقم صفحتها في الأصل.
- **النص منقول حرفيًا** من الصورة الممسوحة، دون تلخيص أو تصحيح. الكلمة غير المقروءة تُكتب `[غير واضح]`.
- رأس كل ملف يذكر أداة الإصدار وتاريخها، وملف المصدر، وحالة المراجعة.
- **الحالة:** "تحويل آلي — يحتاج مراجعة" إلى أن يراجعه صاحب الممارسة أو تُطابَق عينة منه بالأصل، فتصبح "روجع".
- المجلدات بترقيم المجالات نفسه في المكتبة الأصلية (01 إلى 08).
