# الممارسة الاستشارية والمستشار النظامي

منهجيات وخدمات الممارسة الاستشارية، مع واجهة بحث وإجابة في التشريعات.

مصدر مواد الموقع الوحيد هو [saudi-legislation](https://github.com/ahzh999-rgb/saudi-legislation). تبنى نسخة الموقع من commit مثبت مع استبعاد النصوص غير المؤهلة وحفظ حدود التحقق؛ [التشغيل والمزامنة](site/README.md) و[مراجعة تغيير المصدر](site/SOURCE_CHANGE_REVIEW.md).

مجلد `مكتبة-التشريعات` باقٍ للأرشيف، وليس مكتبة مستقلة يجري تحديثها يدوياً لتغذية الموقع. منهجيات الممارسة وسجل الحالات منفصلة عن مجموعة مواد الإجابة المولدة.
